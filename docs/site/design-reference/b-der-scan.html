Bestand in Minuten erfasst.

Ankauf auf dem Tisch, Kiste aus dem Keller, Ware für den nächsten Markt: Karte für Karte unter die Kamera, die Liste schreibt sich selbst.

  • Massenscan

    Karten nacheinander unter die Kamera schieben. Die App zählt mit, erkennt Dubletten und legt Stapel an.

  • Preisverlauf pro Karte

    Jede Karte im Bestand hat ihren Verlauf. Du siehst, was steigt, und entscheidest, wann du verkaufst.

  • Export als Cardmarket-CSV

    Bestand als CSV im Cardmarket-Format, mit Zustand, Sprache und Anzahl. Hochladen statt abtippen.

Open Source

Offen. Und trotzdem bequem.

Der komplette Code liegt offen. Du kannst Voidbinder selbst betreiben oder uns den Server überlassen.

Selbst hosten

0 €

Auf deinem Rechner, deinem NAS oder deinem Server. Deine Daten bleiben, wo du sie hinstellst, und du kannst jede Zeile nachlesen.

$ git clone voidbinder
$ docker compose up -d
